# RecoveryMargin Homepage

Static GitHub Pages-ready homepage for RecoveryMargin.

## Publish on GitHub Pages
1. Create a public repository (e.g. `recoverymargin`).
2. Upload all files in this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. The homepage will be available at `https://<username>.github.io/recoverymargin/`.
